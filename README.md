# Visual World History

An interactive map of where people lived, from 10,000 BCE to 2025, with cited
places, states and events along the way.

**[Open the map](https://splazoosh.github.io/visual-world-history/)**

Colour shows population density on one fixed scale for every year. Press play or
drag the timeline to move through time, and click a marker to read about it and
see its sources. It runs in a desktop browser with WebGL 2 and downloads about
70 MB on first load, less where the host compresses it.

This repository holds the built site. The data, images, text, engine and font
stay under their own licences, listed in
[`NOTICES.txt`](NOTICES.txt) and, item by item, in [`PROVENANCE.md`](PROVENANCE.md).
